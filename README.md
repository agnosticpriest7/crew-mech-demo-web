# Crew Mech - public solo test

A build-only Unity WebGL prototype. Three interior decks, usable ladders, pilot/cannon/engineering stations, cannon and sword combat in an original salt-flat alien range.

**Internet co-op setup is pending.** Host/Join requires separate Unity Cloud, Relay and Authentication setup. This Pages site serves the player files; it does not provide a multiplayer server. Local transport tests are not proof of internet connectivity. Physical Xbox Edge remains untested.

Open the Pages site and click Start, press Enter, or press controller A. Audio may require clicking the canvas. Left stick/WASD moves; right stick/mouse looks; A/E interacts; B leaves; RT fires cannon; RB swings sword from pilot; Menu/Esc pauses; View/M mutes; Y/R rescues. Pilot is upper deck, cannon middle, engineering lower. Rear-right ladder connects the decks.

This repository contains only compiled player files and a launch page. Editable project/model source and source archives are retained privately outside this repository. See release.json for version, source checkpoint and SHA-256 file hashes.
